# this222shallpass

Static artist page. No build step, no dependencies — plain HTML/CSS and ~50 lines of JS.

Two versions of the same site live here. `index.html` is the live one — all
three pages stacked as translucent sheets, the active one on top, navigated by
hash. The flat multi-page version is kept alongside it.

```
index.html          THE SITE — all three pages as a stack of sheets
  stack.css         its styles
  stack.js          sheet shuffling + language toggle

index-alt.html      flat version: landing page
profile.html        flat version: about
days.html           flat version: day tracking
  style.css         their styles
  site.js           language toggle + days rendering

days.js             the list of day images  ← the only file you touch to post
gen-background.py   regenerates the eight background drawings
images/
  bg-01…08.svg      background drawings
  days/             day images
```

Both versions carry the same copy, so **edits have to be made in both places** —
`index.html` holds all three pages as `<section class="sheet">`, and the flat
version splits them across three files.

## Posting a day

1. Drop the image into `images/days/`
2. Add one line at the **top** of the list in `days.js`:

```js
{ file: "2026-07-28.jpg", date: "2026.07.28", en: "note", ja: "メモ" },
```

`en` and `ja` are optional — delete either key to leave it out. Newest first.

Resize before committing. The grid never shows an image wider than ~250px, and
git keeps every version of a binary forever, so a few MB per day adds up fast and
cannot be taken back out. 1600px on the long edge as WebP q92 is the current
setting — that put the first six days at ~70 KB each instead of ~4.5 MB:

```bash
python3 -c 'from PIL import Image;import sys;i=Image.open(sys.argv[1]).convert("RGB");s=1600/max(i.size);i=i.resize([round(d*s) for d in i.size],Image.LANCZOS) if s<1 else i;i.save(sys.argv[2],quality=92,method=6)' in.png images/days/out.webp
```

Full-size originals live outside the repo in `../day-originals/`.

## Backgrounds

Eight drawings are generated by `gen-background.py` — a brutalist complex in
exploded axonometric, each volume ghosted at its original position with hairline
leaders to where it shifted to. Each page uses a different one:

```css
body[data-page="index"]   { --bg-image: url("images/bg-01.svg"); }
body[data-page="profile"] { --bg-image: url("images/bg-04.svg"); }
body[data-page="days"]    { --bg-image: url("images/bg-07.svg"); }
```

Change a number to swap in one of the other five. `stack.css` has the same block
keyed on `html[data-page]`, so shuffling the deck shuffles the background too.

Regenerate them (variants differ in view angle, seed and arrangement):

```bash
python3 gen-background.py
```

Opacity, position and size are the lines under `.bg`, with a mobile override at
the bottom of the file. The drawings carry faint pink "was here" outlines and
blue axis marks, so `.bg` deliberately does **not** apply `grayscale()`.

## Language toggle

Every translated string is two sibling elements:

```html
<span class="en">Profile</span><span class="ja">プロフィール</span>
```

CSS hides one based on `<html lang>`; the button flips it and remembers the choice
in localStorage. All the current copy is placeholder text — search for
"Placeholder" / "プレースホルダー".

## Publishing

The repo must be named `this222shallpass.github.io` for the bare domain to work.

```bash
git init && git add -A && git commit -m "site" && git branch -M main
```

Then add the remote and push; in the repo's Settings → Pages, set the source to
`main` / `/ (root)`.

## Local preview

```bash
python3 -m http.server 8000
```
